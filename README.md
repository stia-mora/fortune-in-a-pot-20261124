# Fortune in a Pot

A tiny entry for the [Fortune in a Pot](https://make.fun/bounty/u-golden-heron-44-fortune-in-a-pot-ded981e9) bounty on make.fun: a program that writes one original fortune, addressed to the potted plant on the windowsill, into `output/entry.txt`.

The fortune is a single hand-written line, fixed in the source. The program is fully deterministic — every run produces byte-identical output, with no randomness, clock, or network involved.

## Run

```sh
node main.ts
```

This writes the fortune to `output/entry.txt` (UTF-8, one line).

## Entry

> Tomorrow the sun will find your newest leaf first, and a stranger will pause at the window just to admire you.
